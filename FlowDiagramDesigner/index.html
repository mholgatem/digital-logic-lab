    Controls

    Drag a palette tileAdd a shape (or click the tile to add it at the centre)
    Click / Shift+clickSelect / add to the selection
    Drag on empty spaceBox-select
    Click a grouped shape againDrill into the group to select the shape inside it
    Drag a port dot, Alt+drag or right-drag a shapeDraw an arrow. Release on a shape or port to connect, on empty space for a free end
    Ctrl+release while drawingPlace a 90° bend and keep drawing; click a shape or empty space to finish
    Drag a 90° segmentSlide it sideways (end segments jog around the port)
    Right-click an arrowInsert a jog, add a label, reset the route
    Drag the round handleRotate in 15° steps; hold Shift to rotate freely
    R / Shift+RRotate the selected shape or label 90° clockwise / anticlockwise
    Double-clickEdit the label of a shape, arrow or group
    Click a selected shape's labelSelect the label to move or rotate it
    Wheel / Shift+drag / middle-dragZoom / pan
    Ctrl+G / Ctrl+Shift+GGroup / ungroup
    Ctrl+Z / Ctrl+YUndo / redo (see History for the full list)
    Ctrl+C / V / DCopy / paste / duplicate
    Arrow keysNudge (hold Shift for 10×)
    DeleteDelete the selection
    ] / [Bring to front / send to back
    F, +, −Fit, zoom in, zoom out
    Ctrl+SSave as .json
